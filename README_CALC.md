# Calculator

Простой калькулятор на Python из практической работы №3.

```python
from calculator import add, subtract

assert add(2, 3) == 5
assert subtract(7, 4) == 3
```

В итоговом файле есть add, subtract и учебный флаг IMPORTANT_FIX.
Экспериментальные multiply и divide оставлены только в hotfix/urgent-fix.
BROKEN_CODE удалён отдельным revert-коммитом.

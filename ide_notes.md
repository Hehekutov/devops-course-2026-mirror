# Git в VS Code и терминале

## Три удобства VS Code
1. Source Control показывает изменённые файлы и позволяет просматривать построчный diff до коммита.
2. Можно добавлять в индекс отдельные изменения и видеть разницу между staged и unstaged.
3. GitLens показывает автора и коммит для строки, историю файла и сравнение версий. Расширение установлено.

## Что удобнее в терминале
Interactive rebase, cherry-pick и настройку нескольких remote удобнее выполнять явными командами: видны параметры, а последовательность легко повторить.

# Подготовка к КР

## Когда выбрать rebase, а когда merge?
Rebase — для актуализации личной неопубликованной ветки перед PR: коммиты переносятся поверх новой базы. Merge — для интеграции общей ветки: сохраняется история без изменения существующих хешей.

## Rebase публичной ветки
Изменятся хеши коммитов. У коллег останется старая история, возникнет расхождение и потребуется согласованное восстановление. Поэтому общую историю не переписываем.

## Зачем нужен multi-remote?
Для резервной копии на другом хостинге, переноса проекта или публикации в корпоративное зеркало. Каждый push проверяется отдельно: операция в два remote не атомарна.

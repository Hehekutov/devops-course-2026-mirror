# Git и SVN

## 1. Почему ветвление в Git считается дешёвым?
Ветка Git — небольшой указатель на коммит. Её создание не копирует все файлы; переключение меняет рабочее дерево при необходимости. Ветки и история доступны локально.
Утверждение о непременно дорогом копировании в SVN неточно: серверная операция svn copy использует cheap copy и тоже не копирует все данные сразу. Отличие в организации: ветки SVN — каталоги централизованного репозитория, операции с удалённым репозиторием требуют связи с сервером.

## 2. Можно ли сделать коммит SVN без интернета?
Коммит требует доступа к серверу репозитория. Для сервера в интернете без связи это невозможно. Если репозиторий находится локально или доступен по локальной сети, интернет не нужен. Офлайн можно редактировать рабочую копию и смотреть diff относительно её базовой версии.

## 3. Где SVN может быть удобнее?
В существующих проектах с инфраструктурой SVN; при централизованном разграничении доступа по каталогам; для крупных бинарных ресурсов, когда команда использует блокировки файлов. Выбор зависит от требований, а не только от возраста системы.
